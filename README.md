# 🏘️ Delhi House Price Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Real Estate](https://img.shields.io/badge/Real_Estate-Delhi-orange.svg)

## 📖 Overview

Regression model specifically for predicting residential property prices in Delhi, India. Analyzes location, size, amenities, and neighborhood characteristics for accurate price estimation.

## 🎯 Features

- Delhi-specific price prediction
- Locality-based analysis
- Property type comparison
- Market trend insights

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Quick Start

```bash
git clone https://github.com/adityavdn/Delhi-House-Price-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Key Features

- Location (Delhi NCR areas)
- BHK Configuration
- Square Footage
- Amenities, Age
